# Английский 3 класс — Верещагина 🦉

Игровое приложение для подготовки к устному экзамену по английскому языку в 3 классе (учебник Верещагиной).

## Что внутри

Все вопросы и ответы строго из учебника — ничего лишнего.

**6 тем:**
- 🍕 Еда
- 🎄 Праздники  
- 🐾 Животные
- 👕 Одежда
- 🌤 Времена года
- 📅 Английский год

**2 режима заданий:**
- 🎯 Выбери правильный ответ из 4 вариантов
- 🔧 Составь ответ из слов

**Игровые элементы:**
- ❤️ 3 жизни
- ⭐ Очки опыта (XP)
- 📊 Прогресс урока
- 💡 Объяснение каждого ответа на русском языке

## Как использовать

Открой `index.html` в браузере — никаких установок не нужно. Работает без интернета.

Или играй онлайн: [deepazone.github.io/DuoDeep](https://deepazone.github.io/DuoDeep)

## Для кого

Для учеников 3 класса и их родителей. Можно заниматься самостоятельно или вместе.
